# جدول تطابق قابلیت‌ها

مرجع کد و hashها در `config/sources.json` و `vendor/studio/sources.json` ثبت شده‌اند. وضعیت فعلی: استخراج از Git انجام شده؛ تطبیق با overrideها و دارایی‌های استودیوی زنده در انتظار خروجی سرور است.

| زیرسامانهٔ مبدأ | محل و رفتار کیت | وضعیت / محدودیت |
| --- | --- | --- |
| ۲۷ template رابط Studio | catalog/studio-ui.json و پرامپت مستقل هر template | همهٔ شناسه‌ها حفظ شده‌اند؛ تست تطابق مجموعهٔ شناسه‌ها |
| ۱۰۷ فیلد initialContent و پیش‌فرض‌ها | کاتالوگ و spec.request.content | حفظ؛ فیلدهای تخصصی قالب حذف نشده‌اند |
| select، input، textarea و کنترل‌های تخصصی | ۴۲۴ رکورد کنترل با برچسب، گزینه، شرط و محل منبع | شامل کنترل‌های کمکی رابط اصلی؛ ادعای ۴۲۴ قابلیت محتوایی مستقل نیست |
| stateها و typeهای رابط | stateDefaults، types و requestBuilders در کاتالوگ | snapshot خام، شامل وضعیت‌های گذرای رابط؛ همه فیلد سفارش نیستند |
| ویرایش متن و قرارداد اسلاید | rules مستقل Reporter و parser اصلی | ۲۱ ماژول پرامپت؛ انتشار سایت اجرا نمی‌شود |
| پرامپت تصویر و تنظیمات هر قالب | برش مستقل render_prompt و validate_request | بدون Worker، صف و فراخوانی AvalAI |
| مرجع مجری و لوکیشن و پروفایل فضایی | انتخاب هوشمند/دستی اصلی و checksum فایل محلی | نبود هویت واقعی مانع تولید همان سفارش است |
| صدا و شخصیت‌ها | کاتالوگ کامل OpenAI/Gemini و لحن در audio spec | اجرای native در صورت وجود؛ فایل ادمین در نبود ابزار |
| ویدیوی Studio | validator، قرارداد سکانس، compiler و مراجع نام‌گذاری‌شده | پرامپت؛ بدون تولید ویدیوی مولد یا مصرف اعتبار |
| video-kit | برندها، فونت‌ها، SFX، کاتالوگ تکنیک، مهارت‌ها و wrapperها | HyperFrames محلی؛ Remotion اختیاری با مجوز خودش |
| پروژه و کتابخانهٔ سفارش | spec/project، منابع، history، REVIEW و ZIP سفارش | محلی و خصوصی؛ کتابخانهٔ کاربران Studio منتقل نمی‌شود |
| ورود، تلگرام، انتشار، باشگاه و تعاملات | خارج از ابزار تولید مستقل | تولید محتوای قالب‌های باشگاه حفظ شده؛ مدیریت اعضا و ارسال محتوا منتقل نشده |

قابلیت وجود یک گزینه با دسترسی به مدل آن متفاوت است. حفظ ساختار و پرامپت تضمین پیکسل‌به‌پیکسلِ خروجی مدل مولد نیست. نتیجهٔ هر سفارش بازبینی جدا می‌خواهد.
