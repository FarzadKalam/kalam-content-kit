# انتقال به محیط‌های دیگر

نسخهٔ اجرایی اصلی Codex است. قواعد، پرامپت‌ها، کاتالوگ و فایل سفارش وابسته به ارائه‌دهنده نیستند؛ دسترسی ابزار در هر محیط متفاوت است.

| محیط | مسیر شروع | محدودیت |
| --- | --- | --- |
| Codex App | بازکردن پوشه و گفت‌وگوی تازه؛ AGENTS.md و Skill پروژه | ابزار تصویر/صدا به حساب و جلسه بستگی دارد |
| Codex وب با محیط اجرا | بازکردن ریپو در فضای قابل نوشتن، خواندن AGENTS.md | بدون فایل و اجرای فرمان، رندر محلی ممکن نیست |
| Claude | کل کیت را در محیط دارای فایل اجرا کنید؛ عامل صریحاً AGENTS.md و SKILL.md را بخواند | کشف خودکار `.agents` فرض نشود؛ وجود تصویرساز/TTS فرض نشود |
| Manus | کپی ریپو و پیام شروع با مسیر AGENTS.md | نصب ابزار و دسترسی فایل/رندر باید همان‌جا بررسی شود |
| Gemini | قواعد و پرامپت قابل انتقال‌اند؛ برای رندر محیط دارای اجرای کد لازم است | چت ساده جای محیط Node/Chromium را نمی‌گیرد؛ ابزار مولد باید واقعاً قابل فراخوانی باشد |

در همهٔ محیط‌ها نام مدل مبدأ را با مدل قابل اجرا یکی نگیرید. اجرای API، ورود خودکار به سرویس دیگر یا تبدیل اشتراک چت به API راه‌حل این کیت نیست. نتایج آن محیط‌ها تا اجرای واقعی، «آزموده‌شده» معرفی نشوند.
