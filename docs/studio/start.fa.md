# شروع کار ادمین

کل پوشه را از ZIP استخراج کنید و در Codex App باز کنید؛ سپس گفت‌وگوی تازه بسازید تا `.agents/skills` کشف شود. فقط فایل SKILL.md یا ZIP بسته‌نشده، نصب کامل کیت نیست. ادمین به حساب GitHub نیاز ندارد. برای Codex وب، محیط اجرای دارای فایل/ترمینال لازم است؛ اگر حساب فقط اتصال به ریپو می‌پذیرد، مسیر پوشهٔ محلی در App را استفاده کنید.

به عامل بگویید AGENTS.md را بخواند، `npm run doctor` را اجرا کند و در صورت نیاز نصب را آماده کند. برای macOS/Linux نصب dependency با `bash scripts/setup.sh` و برای ویندوز `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/setup.ps1` است. ویندوز طبق سیاست فعلی کیت، پوشهٔ کار روی درایو غیر C باشد. نصب ابزار سیستم و sudo خودکار نیست. Python 3.11+، Node 22.12+ و برای رندر مرورگر موجود لازم‌اند؛ در صورت نیاز مسیر Python در KALAM_PYTHON و مرورگر در KALAM_BROWSER_PATH قابل تعیین است. تشخیص مسیر Chrome روی macOS اضافه شده، ولی اجرای آن سیستم در این نسخه هنوز تست نشده است.

پس از آماده‌شدن، کافی است بنویسید:

> برای چناران با این خبر، یک استوری خبر بساز. فقط تیتر و عکس باشد، جای تیتر پایین و لوگو شناور. عکس خودم عیناً حفظ شود.

> از این خبر برای گلبهار یک کاروسل پنج‌اسلایدی بساز. ابتدا متن اسلایدها را بده، سپس با تنظیمات پست استودیو طراحی کن.

> تمام تنظیمات تصویر استودیو را نشان بده؛ دو مجری، حالت چهرهٔ متفاوت و مانیتور با عکس مرجع می‌خواهم.

> همین سفارش را ادامه بده و فقط رنگ و جای تیتر اسلاید دوم را عوض کن؛ متن‌ها همان بمانند.

فایل‌های ورودی را به عامل بدهید یا مسیرشان را مشخص کنید. نام رسانه، هدف و متن قطعی را روشن کنید. لازم نیست همهٔ تنظیمات را از ابتدا بدانید؛ عامل پیشنهاد می‌دهد و تمام گزینه‌ها همچنان قابل دسترسی‌اند. برای درخواست نریشن، ابتدا متن خوانش تأیید می‌شود؛ اگر ابزار داخلی صدا وجود نداشت فایل صوتی خودتان لازم است.

برای تحویل، لینک فایل واقعی و REVIEW.md را دریافت کنید. ZIP سفارش شامل ورودی‌ها و منابع خصوصی است؛ آن را در ریپوی عمومی نگذارید. برای ادامه در گفت‌وگوی تازه، پوشهٔ کامل سفارش لازم است؛ پوشه‌های مخفی `.local` را هنگام جابه‌جایی حذف نکنید.
