# شروع کار ادمین

پوشهٔ کامل ریپو را clone یا کپی کنید و در Codex App باز کنید؛ سپس گفت‌وگوی تازه بسازید تا `.agents/skills` کشف شود. فقط فایل SKILL.md نصب کامل کیت نیست و ZIP جداگانه لازم ندارد. clone ریپوی عمومی بدون حساب GitHub ممکن است. برای Codex وب، محیط اجرای دارای فایل/ترمینال لازم است؛ اگر حساب فقط اتصال به ریپو می‌پذیرد، مسیر پوشهٔ محلی در App را استفاده کنید.

به عامل بگویید AGENTS.md را بخواند، `npm run doctor` را اجرا کند و در صورت نیاز نصب را آماده کند. برای macOS/Linux نصب dependency با `bash scripts/setup.sh` و برای ویندوز `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/setup.ps1` است. ویندوز طبق سیاست فعلی کیت، پوشهٔ کار روی درایو غیر C باشد. نصب ابزار سیستم و sudo خودکار نیست. Python 3.11+، Node 22.12+ و برای رندر مرورگر موجود لازم‌اند؛ در صورت نیاز مسیر Python در KALAM_PYTHON و مرورگر در KALAM_BROWSER_PATH قابل تعیین است. تشخیص مسیر Chrome روی macOS اضافه شده، ولی اجرای آن سیستم در این نسخه هنوز تست نشده است.

پس از آماده‌شدن، کافی است بنویسید:

> برای چناران با این خبر، یک استوری خبر بساز. فقط تیتر و عکس باشد، جای تیتر پایین و لوگو شناور. عکس خودم عیناً حفظ شود.

> از این خبر برای گلبهار یک کاروسل پنج‌اسلایدی بساز. ابتدا متن اسلایدها را بده، سپس با تنظیمات پست استودیو طراحی کن.

> تمام تنظیمات تصویر استودیو را نشان بده؛ دو مجری، حالت چهرهٔ متفاوت و مانیتور با عکس مرجع می‌خواهم.

> همین سفارش را ادامه بده و فقط رنگ و جای تیتر اسلاید دوم را عوض کن؛ متن‌ها همان بمانند.

> برای چناران استوری صبح‌بخیر امروز بساز. تاریخ و ساعت تهران، هوا، اوقات شرعی و مناسبت‌ها را از منبع بگیر و معمای مناسبی پیشنهاد بده.

> برنامهٔ مسابقات این رقابت را برای فردا با ساعت تهران بساز؛ منبع و تاریخ را بررسی کن.

عامل برای قالب‌های مربوط، دادهٔ روز را دریافت و مدرک آن را داخل سفارش نگه می‌دارد. مقادیر دستی شما حفظ می‌شوند. اگر اطلاعات منبع ناقص یا منقضی باشد، عامل از ابزار وب محیط برای همان داده استفاده می‌کند یا موارد لازم را از شما می‌گیرد. خبر را می‌توانید بدهید یا از [خبریاب](news-discovery.fa.md) بخواهید خبر تازه و مناسب رسانه را پیدا و بررسی کند.

محیط محلی Codex روی اندروید طبق تست مالک اجرا شده است؛ راه‌اندازی ادمین‌ها بر همان محیطِ تست‌شده و حساب شخصی هر ادمین بنا می‌شود.

فایل‌های ورودی را به عامل بدهید یا مسیرشان را مشخص کنید. نام رسانه، هدف و متن قطعی را روشن کنید. لازم نیست همهٔ تنظیمات را از ابتدا بدانید؛ عامل پیشنهاد می‌دهد و تمام گزینه‌ها همچنان قابل دسترسی‌اند. برای درخواست نریشن، ابتدا متن خوانش تأیید می‌شود؛ اگر ابزار داخلی صدا وجود نداشت فایل صوتی خودتان لازم است.

خود خروجی‌ها را مستقیماً در همان محیط دریافت می‌کنید؛ عکس تکی، چند عکس، متن یا پرامپت به ZIP نیاز ندارند. فقط اگر بستهٔ پروژه بخواهید یا برای انتقال و ادامهٔ کار لازم باشد، عامل با `content pack` یک ZIP از همان سفارش می‌سازد. ثبت پروژه در Git یا ساخت PR لازم نیست. جزئیات در [راهنمای تحویل](delivery.fa.md) است. ZIP سفارش شامل ورودی‌ها و منابع خصوصی است؛ آن را در ریپوی عمومی نگذارید. برای ادامه در گفت‌وگوی تازه، پوشهٔ کامل سفارش لازم است؛ پوشه‌های مخفی `.local` را هنگام جابه‌جایی حذف نکنید.
