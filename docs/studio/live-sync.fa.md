# دریافت تنظیمات استودیوی زنده

نسخهٔ Git و سرور ممکن است پرامپت متفاوت داشته باشند. این نسخه پیش‌فرض‌های کد و چهار پرامپت production ثبت‌شده در Git را دارد؛ snapshot زنده هنوز دریافت نشده است. نه صرف دریافت فایل و نه import موفق، تأیید تطابق بصری تمام خروجی‌ها محسوب نمی‌شود.

## خروجی فقط‌خواندنی روی سرور

فایل `scripts/export-studio-live.py` مستقل و فقط وابسته به کتابخانهٔ استاندارد Python است. مدیر دارای دسترسی سرور آن را در همان محیط اجرا کند:

```bash
python3 export-studio-live.py --data-dir /var/lib/kalam-design --output /tmp/studio-live.zip
```

اگر KALAM_DATA_DIR متفاوت تنظیم شده، همان مسیر واقعی داده شود. اسکریپت gateway را import نمی‌کند، فایل پیش‌فرض نمی‌سازد، سرویس را تغییر نمی‌دهد و شبکه ندارد. فقط ZIP خروجیِ جدید نوشته می‌شود. مسیر خروجی از قبل موجود باشد، بازنویسی نمی‌شود.

فقط پرامپت‌های مشخص، انتخاب مدل/صدا/رونویسی، پروفایل و تصاویر **مشترک** مجری/لوکیشن/مانیتور استخراج می‌شوند. حساب‌ها، کلیدها، شماره‌ها، سفارش‌ها، فایل‌های scope=project و لینک‌های امضاشده منتقل نمی‌شوند. اگر فایل مشترک در کش سرور نیست، شناسهٔ کسری گزارش می‌شود؛ اسکریپت برای بازیابی به S3 وصل نمی‌شود. مدیر باید فایل‌های مجازِ مفقود را ابتدا در محیط خودش تأمین کند.

## مقایسه و ورود

ZIP از مسیر مورد توافق به این محیط منتقل شود؛ کلید سرور یا توکن در گفت‌وگو فرستاده نشود. سپس:

```bash
python scripts/import-studio-live.py /path/studio-live.zip --check
python scripts/import-studio-live.py /path/studio-live.zip
npm run catalog:studio
npm test
npm run validate
```

import فقط فایل‌های allowlist با checksum معتبر را می‌پذیرد؛ نسخهٔ قبلی زیر `.local/live-imports` نگه‌داری می‌شود. overrideهای حذف‌شدهٔ سرور به مبنای Git بازمی‌گردند. سفارش‌های موجود تنظیمات قبلی خود را حفظ می‌کنند. پس از مقایسهٔ پرامپت‌ها، کنترل کسری دارایی و بازبینی خروجی‌های نماینده، وضعیت تطابق در گزارش ثبت شود؛ liveVerified خودکار true نمی‌شود.

برای به‌روزرسانی کد، checkout مشخص Studio را به `python scripts/import-studio.py <checkout>` بدهید و تغییرات فایل‌های استخراج‌شده، checksumها و کاتالوگ را در یک تغییر مستقل بازبینی کنید. هیچ سفارش معمولی این import را خودکار اجرا نمی‌کند.
