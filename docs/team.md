# استفادهٔ تیمی

ریپوی مشترک با درخواست مالک عمومی است و تمام دارایی‌های مشترک داخل آن نگه‌داری می‌شوند؛ ZIP توزیع ساخته نمی‌شود. clone ریپوی عمومی بدون حساب GitHub ممکن است. اشتراک و امکانات Codex هر ادمین مستقل است؛ هیچ کلید API یا مجوز سرویس از ریپو منتقل نمی‌شود. راهنمای شروع: `studio/start.fa.md`.

پوشهٔ کامل `.local/projects/<id>` شامل ورودی، متن تأییدشده، مرجع، تنظیمات ثابت، timecode، source، تاریخچه و خروجی برای ادامهٔ سفارش لازم است. خود خروجی‌ها طبق [راهنمای تحویل](studio/delivery.fa.md) مستقیماً در همان محیط به کاربر داده شوند؛ ZIP برای عکس تکی، چند عکس، متن و پرامپت لازم نیست. `content pack` فقط برای درخواست بستهٔ پروژه یا نیاز واقعی به انتقال و ادامهٔ آن اجرا شود. تحویل سفارش به commit، push یا PR نیاز ندارد و سفارش و فایل مشتری وارد ریپوی عمومی نمی‌شود.

تغییر ابزار و قواعد مشترک با branch و review انجام شود. سلیقهٔ مشتری فقط در همان پروژه بماند مگر مالک تعمیم آن را خواسته باشد.
