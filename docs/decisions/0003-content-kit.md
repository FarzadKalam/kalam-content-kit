# تصمیم ۰۰۰۳: کیت جامع محتوا

تاریخ ۲۰۲۶-۱۱-۰۳؛ بر اساس تصمیم‌های مالک در همین سفارش.

ریپوی مستقل همراه Skill اصلی، عمومی و شامل دارایی‌های مشترک باشد و یک ZIP کامل بدهد. ادمین برای دانلود به حساب GitHub نیاز ندارد. سیاست خصوصی‌بودن کیت در تصمیم ۰۰۰۱ مربوط به نسخهٔ قبلی است و برای این توزیع جایگزین می‌شود؛ فایل سفارش‌ها همچنان خصوصی‌اند.

Codex App/محیط فایل‌دار اولویت است. گفت‌وگوی فارسی با تمام تنظیمات اختصاصی Studio انجام شود؛ فیلدها و رفتارها به چند پرامپت ساده کاهش نیابند. منطق بدون provider از کد استخراج و نسخه‌بندی شود. پرامپت و تنظیمات زنده پس از export فقط‌خواندنی بر مبنای Git اعمال شوند.

مدل و ابزار داخلی همان حساب استفاده شود؛ کلید API جدا، backend و فراخوانی ارائه‌دهنده لازم نباشد. Skill دسترسی مدل را ایجاد نمی‌کند. نریشن داخلی در صورت وجود و پس از تأیید متن مجاز است؛ در نبود آن، فایل ادمین لازم است. قاعدهٔ «نریشن همیشه بیرون کیت» در نسخهٔ قبل با این رفتار جایگزین می‌شود.

اسلاید در نسخهٔ اول کاروسل و استوری تصویری است. پرامپت ویدیو تحویل داده می‌شود؛ موشن محلی رندر می‌شود. PPTX، تولید ویدیوی مولد، ارسال خودکار محتوا و اجرای تضمین‌شدهٔ محیط‌های دیگر خارج از نسخهٔ اول‌اند.
