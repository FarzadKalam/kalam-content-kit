# تصمیم ۰۰۰۴: دادهٔ عمومی و استفاده از خود ریپو

تاریخ UTC: ۲۰۲۶-۱۱-۰۳؛ در بخش پایانی آزمون، تاریخ تهران ۲۰۲۶-۱۱-۰۴ است. بر اساس درخواست مالک برای تکمیل دریافت دادهٔ روز و نگه‌داری همهٔ فایل‌ها در ریپو.

تمام فایل‌های مشترک داخل ریپو بمانند. ساخت ZIP توزیع، فرمان release و workflow انتشار ZIP حذف شوند. بستهٔ خصوصی یک سفارش و ابزار انتقال یک‌بارهٔ تنظیمات سرور، ابزار نگه‌داری‌اند و توزیع کیت به آن‌ها وابسته نیست.

استفاده از منابع عمومی وب/HTTPS برای تقویم، هوا، اوقات شرعی، مسابقه و نرخ مجاز است؛ شرط بدون API مربوط به تولید مدل با حساب/کلید جداست. دادهٔ عمومی به کلید شخصی نیاز نداشته باشد. پرامپت تصویر و مدل متن همچنان در خود محیط اجرا شوند.

قالب‌های مرتبط اتصال خودکار داده و اعتبار زمانی داشته باشند؛ دادهٔ دستی حفظ شود، هر اسلاید مستقل بماند، ساعت تهران مبنا باشد و مدرک ثبت شود. اگر منبع مستقیم خراب یا مبهم بود، ابزار وب محیط با URL، زمان و شاهد واقعی جایگزین شود؛ دادهٔ حدسی، قدیمی یا نامرتبط مجاز نیست.

با درخواست صریح مالک، جستجوگر خبر، RSS و پایش رسانه در این پروژه وجود نداشته باشد. متن خبر را ادمین می‌دهد. حالت «خبر ورزشی» هم متن ادمین است و اجبار به دریافت مسابقه ندارد.
