# استودیوی محتوای کلام برای Codex

کیت مستقل تیم کلام برای تولید و اصلاح **متن، تصویر، استوری و کاروسل، صوت، پرامپت ویدیو و موشن** با ابزارهای داخلی همان محیط؛ بدون کلید API جداگانه و بدون اتصال به backend استودیو.

۲۷ قالب تصویری، ۱۰۷ فیلد محتوا، تنظیمات و شرط‌های فرم Studio، پرامپت‌های اختصاصی و ابزارهای video-kit در این بسته نگه‌داری می‌شوند. ادمین به فارسی سفارش می‌دهد؛ تنظیمات هر قالب همچنان قابل انتخاب‌اند.

## شروع با ریپو

۱. پوشهٔ کامل ریپو را clone یا کپی کنید. تمام Skillها، تنظیمات، فونت‌ها، برندها، ابزارها و راهنماها داخل همان ریپو هستند؛ ZIP جداگانه و مرحلهٔ ساخت بسته لازم نیست. clone ریپوی عمومی به حساب GitHub نیاز ندارد.

۲. پوشه را در Codex App باز کنید و گفت‌وگوی تازه بسازید. در محیط ابری، ریپو در محیط دارای دسترسی فایل و اجرای فرمان باز شود. محیط چتِ فاقد فایل/رندر نمی‌تواند صرفاً با دریافت SKILL.md ویدیو بسازد.

۳. این پیام را بفرستید:

> AGENTS.md و مهارت kalam-studio را بخوان. کیت را برای همین محیط آماده کن و ابزارهای واقعی تصویر و صدا را بررسی کن. تنظیمات و قابلیت‌های استودیو را حفظ کن. برای کلام تازه گلبهار از این محتوا [فایل یا متن] یک [نوع خروجی] بساز. سؤال‌های ضروری را یک‌جا بپرس.

آماده‌سازی را عامل انجام می‌دهد. Node.js 22.12+ و Python 3.11+ لازم‌اند؛ برای موشن مرورگر Chrome/Chromium/Edge موجود هم لازم است. نصب اولیهٔ dependency اینترنت می‌خواهد. فونت‌ها، برندها و SFX مشترک داخل همین بسته‌اند. راهنمای نصب: [شروع ادمین](docs/studio/start.fa.md).

## چه چیزهایی منتقل شده‌اند؟

| مسیر | خروجی |
| --- | --- |
| متن | ویرایش خبر و پیام مردمی، تیتر، پست، کانال، سایت، استوری، تحلیل، سناریو و دادهٔ اینفوگرافی |
| تصویر | همهٔ قالب‌های Studio، پوستر، استیکر شفاف، حفظ عکس، مرجع، اصلاح تصویر و تصویر استودیو |
| اسلاید | کاروسل و استوری با متن، چیدمان، مرجع و تنظیمات مستقل هر اسلاید |
| صوت | نریشن با ابزار داخلی در صورت وجود؛ در غیر این صورت فایل ادمین؛ تدوین و میکس محلی |
| پرامپت ویدیو | بستهٔ Veo / Omni، تنظیمات کارگردانی و مراجع با نام فایل دقیق |
| موشن | منبع قابل ویرایش و MP4 با HyperFrames؛ Remotion اختیاری |
| دادهٔ روز | تاریخ تهران، هوا، اوقات شرعی، هفته و تعطیلی، مناسبت‌ها، مسابقات و نرخ‌ها؛ همراه منبع و اعتبار زمانی |

نام مدل‌ها و شخصیت‌های صوتی فعلی Studio حفظ شده است؛ در دسترس بودن آن‌ها به ابزارهای حساب بستگی دارد. Skill مدل جدیدی به حساب اضافه نمی‌کند. نبود تصویرساز یا نریشن، مجوز استفادهٔ پنهان از API بیرونی نیست. تولید ویدیوی مولد، انتشار در شبکه‌ها و پاورپوینت جزو نسخهٔ اول نیستند.

داده‌های روز با درخواست عمومی HTTPS و بدون کلید مدل دریافت می‌شوند. منبع خراب، نرخ بی‌تاریخ یا ساعت مسابقهٔ تأییدنشده با حدس جایگزین نمی‌شود؛ عامل مسیر وب مستند یا دادهٔ تأییدشدهٔ ادمین را استفاده می‌کند. [راهنمای دادهٔ روز](docs/studio/public-data.fa.md). **جستجوگر خبر، RSS و پایش خبر در این پروژه نیست؛ خبر را ادمین می‌دهد.**

## تنظیمات و تطابق

- [جدول تطابق](docs/studio/parity.fa.md) و کاتالوگ تنظیمات در `catalog/studio-ui.json`؛ شناسه‌ها، فیلدها، گزینه‌ها، پیش‌فرض‌ها، شرط‌های رابط و سازندهٔ payload ثبت شده‌اند.
- پرامپت‌های production ثبت‌شده در Git اعمال شده‌اند. **تنظیمات استودیوی زنده هنوز وارد نشده‌اند**؛ وضعیت در `config/studio/status.json` است. [دریافت و تطبیق نسخهٔ زنده](docs/studio/live-sync.fa.md).
- هر سفارش، نسخهٔ تنظیمات خودش را دارد؛ تغییر تنظیمات مشترک سفارش‌های قبلی را تغییر نمی‌دهد.
- [شواهد آزمون همین نسخه](docs/studio/verification.fa.md) را از سوابق video-kit متمایز بخوانید.

## برای نگه‌دارندهٔ کیت

```bash
npm run content -- settings
npm run content -- new --id my-news --kind image --brand golbahar --template news_story
npm run content -- resume my-news
npm test
npm run validate
npm run content -- refresh my-news
npm run data -- catalog
```

`content brief` دادهٔ عمومی لازم را در صورت نیاز به‌روز و دستور تولید را آماده می‌کند؛ خود مدل تولید محتوا با ابزار داخلی واقعی عامل اجرا می‌شود. جزئیات فرمان‌ها: `npm run content -- help`. کاتالوگ تکنیک‌های موشن و نمونهٔ فونت‌ها همچنان در `library/` موجودند.

ریپو شامل فایل‌های مشترک است. سفارش‌ها، صوت و ویدیوی مشتری، خروجی‌ها، snapshotهای دریافت داده و اطلاعات ورود زیر `.local`/`.cache` باقی می‌مانند و عمومی نمی‌شوند. `content pack` فقط برای انتقال خصوصی یک سفارش اختیاری است و بخشی از توزیع کیت نیست. مجوزهای اصلی و ثالث در [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md) حفظ شده‌اند.

پشتیبانی آزموده‌شدهٔ نسخهٔ حاضر: Codex روی Linux x64. [راهنمای Claude، Manus و Gemini](docs/studio/portability.fa.md) محدودیت‌های انتقال را توضیح می‌دهد؛ اجرای کامل آن محیط‌ها ادعا نمی‌شود.
